# مغناطيس الصور بالواقع المعزز (AR) 🧲✨

## الملفات
- `index.html` — الصفحة اللي الزبون بيفتحها لما يعمل سكان للـ QR
- `tool.html` — أداتك أنت: بتطلع ملف التتبع من الصورة وتعمل الـ QR
- `customers/` — فيها فولدر لكل زبون

## أول مرة بس (تجهيز الموقع)
1. اعمل حساب على github.com
2. اعمل Repository جديد اسمه `ar-magnets` وخليه **Public**
3. ارفع `index.html` و`tool.html` و`README.md` (Add file ← Upload files)
4. ادخل Settings ← Pages ← Branch: `main` / `root` ← Save
5. استنى دقيقة أو اتنين، وموقعك هيبقى على اللينك ده:
   `https://USERNAME.github.io/ar-magnets/`

## لكل زبون
1. افتح `https://USERNAME.github.io/ar-magnets/tool.html`
2. اختار صورة الزبون واضغط "جهّز ملف target.mind"، والملف هينزل عندك
3. على GitHub: Add file ← Upload files، واسحب الملفين، واكتب في اسم الملف المسار كامل، مثلاً:
   `customers/ahmed01/target.mind` و `customers/ahmed01/video.mp4`
   (الأسهل: ارفع الملفين جوه فولدر اسمه `ahmed01` جوه `customers`)
4. ارجع للأداة، اكتب `ahmed01`، واعمل الـ QR ونزّله
5. اطبع الصورة على المغناطيس والـ QR على ستيكر
6. جرّب بنفسك قبل التسليم

## شروط مهمة
- الصورة المطبوعة لازم تكون **هي نفسها** اللي عملت منها target.mind
- اسم الفيديو لازم يكون `video.mp4` بالظبط، وأقل من 25 ميجا (حد الرفع من المتصفح). الأفضل يكون أقل من 10 ميجا
- يُفضل الفيديو يكون بنفس أبعاد الصورة ويبدأ بنفس اللقطة
- الصور اللي فيها تفاصيل وألوان كتير بتتعرف أسرع، والصور السادة أو الفاتحة جداً بيصعب التعرف عليها
- الطباعة المطفية (Matte) أحسن من اللامعة
- أي تعديل بترفعه بياخد دقيقة أو اتنين لحد ما يظهر على الموقع

## ملحوظة خصوصية
الـ Repository عام، يعني أي حد يعرف اللينك يقدر يشوف الفيديو. سمّي الفولدرات بأسماء صعب حد يخمنها (زي `ahmed-7k2q`)، وقول للزبون إن الفيديو هيترفع أونلاين.
